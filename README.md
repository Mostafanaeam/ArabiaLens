# 🌍 ArabiaLens

**ArabiaLens** is a modern, responsive web application designed to showcase the beauty and essential information of the Arab World. It serves as an interactive educational hub featuring dynamic content, maps, and cultural insights.

**ArabiaLens** هو تطبيق ويب عصري وتفاعلي يهدف لاستكشاف الدول العربية، مع عرض أهم المعلومات، الخرائط، والمعالم السياحية لكل دولة بأسلوب شيق وجذاب.

---

## ✨ Features | المميزات

- **🌗 Dark/Light Mode:** Seamless theme toggling with persistent user preference.
- **🌐 Bilingual Support (AR/EN):** Full translation with automatic RTL/LTR layout switching.
- **🗺️ Interactive Maps:** Embedded Google Maps for every country.
- **📱 Fully Responsive:** Optimized for Mobile, Tablet, and Desktop screens.
- **ℹ️ Detailed Modals:** Pop-up views with country bio, flag, landmarks, and Wikipedia links.
- **⚡ Pure Performance:** Built with Vanilla JavaScript, HTML5, and CSS3 (No heavy frameworks).

---

## 🛠️ Tech Stack | التقنيات المستخدمة

- **HTML5:** Semantic structure.
- **CSS3:** Flexbox, Grid, CSS Variables for theming.
- **JavaScript (ES6+):** DOM manipulation, dynamic rendering, and logic.
- **FontAwesome:** For UI icons.
